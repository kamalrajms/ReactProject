## react intro

    What is React?

    1) React is a JavaScript library (not a framework) developed by Facebook (Meta) for building user interfaces (UIs), especially Single Page Applications (SPAs).

    2) It helps developers build reusable UI components that update efficiently when data changes.

    Instead of reloading a whole webpage when something changes, React updates only the parts of the UI that need to change.

    -------
    Why do we need React?

	It makes UI development faster, cleaner, and more efficient.

	Provides a better user experience with smooth updates without page reloads.

## useActionStateHook()

    useActionStateHook is a react hook used to track and  manage the state of asynchronous action
    -like submitting a from or performing an operator -- without manually writing a lot of
    useState and useEffect logic.

            helps in
                the pending (loading) state
                the result (successs or failure) state
                the error (if the action throws an execeptaion)

    synt:
        const [state,formActon,isPending]=useActionStateHook(action,initial_state)

        action-- a function that perform the asyn work (like form submitting data)
        initial_state-- the starting value of your state (null or {})

        state--result (or error) returned fromm the action.
        formActon-- function you can   or use in a form  action attribute.
        isPending -- boolean that teels if the action is currently running.
